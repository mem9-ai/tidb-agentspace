# ADR 0054: Private CSV workspace for a local agent

[GH-222](../../specs/gh-222/spec.md) adds a native, no-account entry separate from the public sales example. A project-scoped 256-bit capability lives in the OS credential store. HTTPS requests use a dedicated CSV authorization scheme. Browser credentials and origins are rejected. The capability grants only enrollment of its own Guest and conditional access to one fixed CSV. It cannot select a browser owner, issue keys, publish a private result, spend money or access account Workspaces.

Enrollment reuses Guest admission, Global identity provisioning, regional policy installation and the existing cleanup queue. A domain-separated ID and verifier, conditional Global registration and idempotent default File System creation make replay select the same workspace and the original 48-hour deadline. Source reads authenticate against the installed Region policy even when Global is offline. The internal owner credential stays within the server for the fixed operations. The real file provider enforces conditional writes. The source is limited to 1 MiB.

The installed helper binds the service and canonical project directory under the current OS user. It serializes local enrollment, checks the remote file version, verifies uploaded bytes and reuses a verified local cache or downloads the saved source. On expiry the next use removes the local secret and retains local files. Another enrollment requires an explicit new request. Agent-generated private reports remain local by default.
